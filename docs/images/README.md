# Product images

These are unmodified official editor images from the published
[Highstead 0.1.2 source archive](https://github.com/idlefoundry/highstead/releases/download/v0.1.2/Highstead-0.1.2-source.tar.gz),
implementation commit `62c57c22752e5b0c2a4fd2c848f321837031c7d5`.

| File here | Original archive path |
| --- | --- |
| `highstead-keyboard.png` | `docs/images/quick-start/01-install.png` |
| `highstead-voices.png` | `docs/images/quick-start/05-voices.png` |

The original image guide describes them as frames drawn by Highstead’s real editor
without a host or window, then cropped and reduced for documentation. They are not
captures from a particular DAW. They show the built-in WORN look; settings and
window layout can differ in use.
